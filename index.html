Technology stack

☁️

AWS EC2

Cloud compute infrastructure providing a Linux environment for hosting the application.

🐳

Docker

Packages the web server and website into a portable, reproducible container image.

🌐

NGINX

Serves the website over HTTP through port 80 using a lightweight NGINX container image.

Deployment overview

ubuntu@ec2: ~/nginx-docker-project
# Build the Docker image
$ docker build -t my-nginx-site:1.0 .
# Run the container on port 80
$ docker run -d -p 80:80 my-nginx-site:1.0
# Verify the running container
$ docker ps
✓ Deployment configuration ready
